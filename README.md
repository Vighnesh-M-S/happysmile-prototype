# HappySmile AI voice assistant: prototype

A clickable front-end prototype for a product case study. HappySmile is a fictional chain of dental clinics in India. The prototype has no backend, and all data is mock data.

- **Patient view** (`/`): the confirmation screen a patient sees after submitting an enquiry.
- **Clinic view** (`/#inbox`): the front-desk lead inbox for the 3 pilot clinics.

It's a single static `index.html` that loads React, Tailwind and Babel from CDNs. There's no build step. Open the file in a browser, or serve the folder with any static host.
